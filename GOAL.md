# Goal

**One command that answers "why is this line like this?" by following a line of code to the commit, pull request, linked issues and review discussion behind it.**

In scope: blame → forge metadata (PRs, issues, reviews) for a line or range; terminal + JSON output; editor-agnostic integration; other forges (GitLab, Gitea) later.
Out of scope: a full git GUI, code search, LLM-generated guesses presented as facts, editing history, hosting a service.
