A

One command

pipx install git+https://github.com/Blackman99/linelore

linelore src/requests/utils.py:795

Python 3.9+ and git, no dependencies. Uses your gh login or GH_TOKEN, and works anonymously on public repos. Pass file:10-30 for a range (commits deduped). --json for editors and scripts, --offline for local only, --rev to blame at a tag.

B

Four hops

  1. 01

    Line → commit

    git blame --porcelain -w -C -M -L … (single line or a range; commits deduped). Skips .git-blame-ignore-revs. Local, no network.

  2. 02

    Commit → pull request

    GET /repos/{owner}/{repo}/commits/{sha}/pulls finds the PR that merged it, including squash and rebase merges.

  3. 03

    PR → issues

    GraphQL closingIssuesReferences lists the issues the PR closed. If that is empty, Fixes/Closes/Resolves #N in the title or body are promoted. Any other #123 stays a mention.

  4. 04

    PR → review

    GET /repos/{owner}/{repo}/pulls/{n}/comments, matched to the line's position in that commit. Comments from elsewhere in the file are labelled as such.
