How to read a card

  1. Commit. git blame on that one line, ignoring whitespace and anything in .git-blame-ignore-revs.local, no network
  2. Pull request. The PR that merged the commit, with the first lines of its description: usually where the reason lives.GitHub API
  3. Issues. Issues the PR closed, plus any other #123 it mentions.cross-references
  4. Review notes. Review comments left near that line, nearest first.the argument you missed
