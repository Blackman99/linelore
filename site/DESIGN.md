# linelore landing page design brief

**Reference object:** a library card catalog — oak drawer, manila 3x5 index cards with a punched rod hole,
typewritten entries, a red "see also" cross-reference line, and a rubber date-due stamp.
A line of code is a book; linelore pulls its cards: commit → pull request → issue → review note.

- **Palette:** manila card #f3e9cf, oak drawer #6b4a2b / #4a321c, typewriter ink #2a2118, ruled-line blue #8fa6c0,
  stamp red #b5452f. Light, warm, paper. No dark-gradient, no glow.
- **Type:** headings in a bookish serif (Iowan Old Style / Palatino / Georgia system stack); card entries in a
  typewriter face (Courier Prime-like system "Courier New"). No Inter.
- **Layout:** one centred oak drawer as hero; cards stand in it with tabs. Below, "how to read a card" laid out as
  a single tall card with ruled lines and margin notes (not feature columns), then install as a borrowing slip.
- **Animation:** cards rise out of the drawer one by one, text is typed, then a red stamp lands (the "why").
  Hover/tap a tab to pull that card forward. Install slip gets stamped on copy.
  `prefers-reduced-motion`: all cards shown, no typing or stamp motion.
- **Banned-trope check:** no dark bg / cyan-purple gradient / gradient text / glow / glassmorphism / left-copy-right-card hero /
  3-column features / SaaS template / Inter+mono. ✔ Distinct from toolsmoke (inspection report), agentckpt, certfan (key pegboard).
